# LaunchLab_UniFAP_Coleta_Seletiva Inteligente

Sistema desenvolvido para otimizar a coleta de materiais recicláveis em
cooperativas de bairros periféricos, considerando o volume ocupado pelos
materiais e a capacidade máxima dos caminhões.

## Objetivo

Reduzir deslocamentos desnecessários e o desperdício de combustível por meio
do processamento dos dados de descarte e do cálculo do volume real dos
materiais coletados.
